# 🛒 বাজার দর | BazarDor

### Know Today's Market Prices at a Glance 🇧🇩

**বাজার দর (BazarDor)** is a responsive web application that helps users explore the prices of daily essential products in Bangladesh. Users can view current prices, compare market rates, and track which products have increased or decreased in price.

## 🚀 Live Demo

🔗 **Live Website:** https://bazar-dor-eight-pi.vercel.app/

🔗 **GitHub Repository:** https://github.com/SobojCoder/bazar-dor

---

## 📝 Project Description

BazarDor makes it easier for people to stay informed about everyday market prices through a simple, user-friendly interface. The application displays product information, price changes, category-wise products, and market-wise price comparisons.

## 🛠️ Technologies Used

- **Next.js** — React framework for routing and web application development
- **React** — Building reusable UI components
- **TypeScript** — Type-safe and maintainable code
- **Tailwind CSS** — Responsive and modern UI design
- **Better Auth** — User authentication and account management
- **REST API** — Fetching product and category information
- **React Hot Toast** — Displaying success and error notifications
- **Git & GitHub** — Version control and source code management

## ✨ Key Features

1. **📊 Daily Product Prices** — View the prices of essential products in Bangladesh.
2. **📈 Price Increase and Decrease** — Explore products whose prices have increased or decreased.
3. **🗂️ Category-Based Browsing** — Browse products by category and sort them by price.
4. **🔎 Product Details and Market Comparison** — View product information, minimum, maximum, average, and market-wise prices.
5. **🔐 Authentication and Profile Management** — Sign up, sign in, use supported social login providers, and update profile information.

## 📱 Responsive Design

BazarDor is designed to provide a user-friendly experience on mobile phones, tablets, laptops, and desktop computers.
